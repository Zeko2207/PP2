# TSIS 3: Racer Game

Run:

```bash
pip install pygame
python main.py
```

Controls:

- Left / Right arrows or A / D: change lane
- Up / Down: small vertical movement
- Esc during game: end run and return to Game Over screen

Features:

- Lane hazards and safe paths
- Dynamic road events: moving barrier, speed bump, nitro strip
- Traffic cars and road obstacles
- Weighted coins
- Enemy speed increases after collecting coins
- Nitro, Shield, Repair power-ups
- Difficulty scaling
- Username entry
- Settings saved in `settings.json`
- Top 10 leaderboard saved in `leaderboard.json`
- Main Menu, Settings, Game Over, and Leaderboard screens
